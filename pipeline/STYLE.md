## ネタ選び(いちばん重要。利用者指示 2026-11-06)
**ジャンルは政治ニュースに固定**: その日いちばん話題になっている「日本の最新政治ニュース」と「世界の政治ニュース」から選ぶ。
- 候補は日本政治3本+世界政治3本を出し、次の4つを各0〜3点で採点して最高点を選ぶ。同点なら日本政治を優先(視聴者は日本)
- 日本政治と世界政治は交互になるように意識する(同じ側が3日続いたら逆側を選ぶ)
- 「政治は週2本まで」の制限は 2026-11-06 の利用者指示で廃止済み(週次タスクの文面には残っているが、こちらが新しい)
1. 今みんなが話しているか: Yahoo!ニュースのトピックス上位、Xのトレンド、Googleトレンド(日本)で上位か。1時間以内に新しい投稿が増えているか(TikTok でもその語で検索して1時間以内の新着が複数あるか。出典D)
2. 自分の生活に関係するか: 財布(税・給付・物価)、仕事、安全(安保・災害対応)、子ども・学校。世界政治なら「日本にどう響くか」を1シーン入れる
3. 感情が動くか: 驚き(意外な数字)、怒り、不安、感動のどれかがあるか
4. 人に話したくなるか: 「知ってた?」と言いたくなる、保存して見返したくなる
合計8点未満しかない日は、点数が最高の政治ネタをそのまま使う(他ジャンルには逃げない)。
NG: 投資の推奨、被害者の個人情報、未成年、根拠のないうわさ、特定の政党・候補への賛否の表明(事実と数字を両論で伝える)。
伝え方: 「誰が・何を決めた/言った」→「いつから・いくら・何人」の数字→「あなたの生活にどう関係」→最後に問いかけ。

### テーマの配分(週7本の目安。2026-11-09 更新)
- 政治固定は維持。配分は **世界政治 4本・日本政治 3本** を目安に、交互ルールの範囲で世界政治を1本多くする
  - 理由: 今週、視聴割合の上位2本はどちらも米中間選挙(世界政治・速報型)。日本政治は再生数は取れるが視聴割合が低い
- 同じ側の中では「**選挙・採決・票数などの数字が主役になる速報型**」を優先する(11/07 型)。人事・交渉の経過のような「数字が弱い」ネタは、視聴割合が低い(11/09 イスラエル組閣 4%)
- 続報は「前回からどこが変わったか」の1点に絞る(同じ数字の繰り返しは 11/05→11/08 の消費税のように視聴割合が伸びない)

## 台本
- 最初の1秒で話し始める。挨拶・前置きなし。1行目は「意外な数字」か「結論」か「問い」(結論先出し・数字提示・疑問形が冒頭3秒の定番。出典B、C)
- 【変更】**つかみシーン(シーン1)は5秒以内**。見どころ予告は「3つ」→「1つ」にし、「〜を60秒で見ていきます」の決まり文句は言わない。
  - 理由: 今週の平均視聴6〜16秒に対し、つかみシーンが12〜17秒(ストーリーズ予告版の長さ=hook_end)。予告を聞き終える前に離脱している。冒頭3秒で6割が離脱する、という業界の目安(出典A)とも一致
  - 出典: A(冒頭3秒、イントロ的な前置きは15〜25%を失う)、B(結論先出し・疑問提起・数字提示)、D(3秒で「何の動画か」を提示、前置き・挨拶は離脱)
- 3秒以内に「この動画で何が分かるか」が伝わる
- 【変更】ナレーション合計 **280〜340文字、動画 61〜70秒**(TikTok 収益化のため61秒以上は維持)。長くなるなら内容を削る
  - 理由: 今週、77秒の2本(11/08・11/09)は視聴割合12%・4%、65秒の1本(11/07)は24%。尺が長いほど最後まで見られていない
  - 出典: E(リールは45〜75秒を基準に、自分のインサイトで尺ごとの続き方を比べる)、A(平均視聴率50%以上を目標)
- 構成: つかみ(≦5秒、数字か結論) → 何が起きた → なぜ/背景 → 「あなたにどう関係」 → これからどうなる → 締め(問いかけ+「フォローして次も」)
- 【追加】1本に1つ「**人に送りたくなる1枚**」を入れる: 比較表・ビフォーアフター・票数や金額の一覧など、スクショして人に送れる画面。ナレーションで「ここだけ保存しておくと便利」と一言添えてよい
  - 理由: 今週は保存・シェアが全本0。Instagram は DM での「送信」をいちばん重く見ている(出典F、G)。保存されやすいのは「具体的な数値・比較表」(出典E)
- 【追加】最後の問いかけは **2択**(A か B か)にし、言い切らずに終える(「選択形式」「最後の1文を未完了に」がコメントを生む。出典E)。最初のコメントも同じ2択にする
- 中立。断定・あおり・一方の立場に寄る言い方は避ける。投資のすすめ、被害者の個人情報は扱わない
- 「60秒ニュース」というシリーズ名を字幕の冒頭か末尾に毎回入れる(解説系はシリーズ化で同じ視聴者に出やすい。出典D)

## 画面
- 1〜3秒に1回は画面が変わる(シーン切替・チップの出現・数字の拡大・ズーム)(2〜4秒ごとのカットでテンポを保つ。出典D)
- 【追加】6〜8秒ごとに「新しい情報か新しい画」を出す(ズームイン/アウト、数字の差し替え、背景写真の切替)。同じ写真+同じ見出しのまま10秒以上続けない(出典A「6〜8秒ごとのリフレーム」、出典F「3〜5秒ごとのジャンプカット」)
- 字幕は常に表示。1行10〜15文字、2〜3行まで。白文字+黒縁取り、強調語は黄色。冒頭の1フレーム目から字幕を出す(音声オフでも分かるように。出典B)
- 字幕とメイン情報は画面の中央〜やや上。下20%(TikTok/リールのUIに隠れる)には置かない
- 冒頭の1フレームが動画の中でいちばん目を引く画にする(大きな数字か太い見出し)。タイトルカードやロゴだけの画面は置かない(出典A)
- 背景色はシーンごとに変える(make_video.py のテーマが自動で変える)。カテゴリでも変える
- 1本に1つは「大きな数字」のシーンを入れる(今週いちばん伸びた11/07は冒頭が「54・44・残り2」の数字)

## 投稿
- 毎朝7時前後(朝7〜9時は反応が良い時間帯の一つ。出典F)。同じシリーズ名「60秒ニュース」で続ける
- キャプション1行目は動画の要点。検索される言葉(固有名詞)を**最初の2文**と字幕の両方に入れる(キャプション・字幕・音声が検索対象。出典F、G)
- 【変更】ハッシュタグは **3〜5個**: #ニュース #60秒ニュース + テーマの固有名詞1〜3個
  - 理由: Instagram は 2025年12月にハッシュタグ上限を5個にしたとされる(出典F)。数より本文の検索語が効く(出典G)
- リール投稿後すぐに予告版をストーリーズへ(投稿後1時間以内の再シェアが効く。出典E)。予告版はつかみ5秒+「続きはリールで」になる
- TikTok: 1分超(収益化条件)。リール: 61〜70秒
- 自分の投稿への自動いいね・自動コメント、他人の投稿への自動反応はしない(規約違反)。最初のコメントも API が拒否する日は手動に回す

## 計測(毎週月曜に見る)
- 指標は「views(再生)」「reach」「ig_reels_avg_watch_time(ミリ秒)」「saved」「shares」。Graph API v25.0 では `plays` は使えず `views` を使う
- 【変更】いちばん重要なのは **平均視聴時間 ÷ 尺(視聴割合)**。目標は 50%(出典A)。当面の目標は来週 25%以上(今週の最高24%)
- 視聴割合が 15% 未満なら冒頭(つかみ)を作り直す。保存・シェアが0の週が続けば「送りたくなる1枚」を見直す
- 伸びたテーマ(保存・シェア・視聴割合が高いもの)を翌週に増やす。再生数だけで判断しない(再生133の11/08より、106の11/07の方が最後まで見られている)
