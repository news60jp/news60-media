# 60秒ニュース スタイルガイド(毎週の調査で更新する)

最終更新: 2026-11-05(初版。調査記事の要点をもとに作成)

## ネタ選び(いちばん重要。安全さより「止まるか」で選ぶ)
候補を5本出し、次の4つを各0〜3点で採点し、合計が最高のものを選ぶ。同点なら「自分の生活に関係する」を優先。
1. 今みんなが話しているか: Yahoo!ニュースのトピックス上位、Xのトレンド、Googleトレンド(日本)で上位か。1時間以内に新しい投稿が増えているか
2. 自分の生活に関係するか: 財布(税・物価・給料・年金)、仕事、天気・災害、健康、子ども・学校
3. 感情が動くか: 驚き(意外な数字)、怒り、不安、感動のどれかがあるか
4. 人に話したくなるか: 「知ってた?」と言いたくなる、保存して見返したくなる
合計8点未満のネタは選ばない。書道のユネスコ登録のような「立派だが誰も止まらない」ネタは、別の日の2本目に回す。
NG: 投資の推奨、被害者の個人情報、未成年、根拠のないうわさ。政治ネタは財布に関わるもの(税・給付・物価対策)を優先し、政局(人事・派閥)は避ける。

## 台本
- 最初の1秒で話し始める。挨拶・前置きなし。1行目は「何が起きたか」か「意外な数字」か「問い」
- 3秒以内に「この動画で何が分かるか」が伝わる
- ナレーション合計 280〜380文字、動画 61〜90秒。長くなるなら内容を削る
- 構成: つかみ(1シーン) → 何が起きた → なぜ/背景 → これからどうなる → 締め(「フォローして次も」)
- 中立。断定・あおり・一方の立場に寄る言い方は避ける。投資のすすめ、被害者の個人情報は扱わない

## 画面
- 1〜3秒に1回は画面が変わる(シーン切替・チップの出現・数字の拡大・ズーム)
- 字幕は常に表示。1行10〜15文字、2〜3行まで。白文字+黒縁取り、強調語は黄色
- 字幕とメイン情報は画面の中央〜やや上。下20%(TikTok/リールのUIに隠れる)には置かない
- 冒頭の1フレームが動画の中でいちばん目を引く画にする(大きな数字か太い見出し)
- 背景色はシーンごとに変える(make_video.py のテーマが自動で変える)。カテゴリでも変える
- 1本に1つは「大きな数字」のシーンを入れる

## 投稿
- 毎朝7時前後。同じシリーズ名「60秒ニュース」で続ける(シリーズ化で同じ視聴者に出やすい)
- キャプション1行目は動画の要点。検索される言葉(固有名詞)を字幕と説明文の両方に入れる
- ハッシュタグは5〜8個: #ニュース #60秒ニュース #時事 + テーマの固有名詞
- TikTok: 1分超(収益化条件)。リール: 90秒以内

## 計測(毎週月曜に見る)
- 完走率(いちばん重要)、平均視聴時間、3秒離脱率
- 3秒離脱が40%超なら冒頭を作り直す。完走率が低ければ尺を削る
- 伸びたテーマ(保存・シェアが多いもの)を翌週に増やす
